Toolchain

Install uqulang

The toolchain is one binary called uqu: compiler, test runner, formatter and package fetcher. It installs into a single directory and can be removed by deleting that directory.

Current release: 0.1.0 · Licensed software · all builds and checksums in the licence portal

You need a licence key.

The toolchain is licensed per institution. Your licence key comes from your university’s administrator, or from the licence portal if you hold the site licence. No key yet? Request a campus licence — evaluation keys are available for teaching staff.

0.1 is a preview release.

Breaking language changes are still expected between 0.x releases. Pin an exact version for a course that is already running, and read the release notes before upgrading mid-semester.

Install with the script

The script downloads the build for your platform, verifies its SHA-256 checksum against the signed manifest, unpacks it into ~/.uqulang and registers your licence key. Nothing is written outside your home directory and nothing needs sudo.

macOS

macOS 13 or newer, on Apple silicon or Intel.

$ curl -fsSL https://get.uqulang.com/install.sh | sh $ uqu licence activate UQU-XXXX-XXXX-XXXX

Or with Homebrew:

$ brew install uqulang

Linux

glibc 2.31+ or musl, on x86-64 or aarch64.

$ curl -fsSL https://get.uqulang.com/install.sh | sh $ uqu licence activate UQU-XXXX-XXXX-XXXX

Prefer to inspect the script before running it? That is the right instinct — download it first, read it, then run it:

$ curl -fsSLO https://get.uqulang.com/install.sh $ less install.sh $ sh install.sh

Windows

Windows 10 22H2 or newer, x86-64 or arm64.

> winget install uqulang.uqu

In PowerShell, without a package manager:

> irm https://get.uqulang.com/install.ps1 | iex

Verify the install

Every release publishes a SHA256SUMS file and a detached signature. Verifying takes ten seconds and is worth doing on any machine you care about:

$ uqu --version uqu 0.1.0 (preview) aarch64-apple-darwin $ uqu doctor toolchain ~/.uqulang/0.1.0 licence site (King Example University) — valid to 2027-08-31 linker cc (found) target aarch64-apple-darwin cache ~/.uqulang/cache (0 B) status ready

uqu doctor is the first thing to run when something looks wrong, and the first thing to paste into a bug report.

Lab and offline deployment

A teaching lab usually cannot run an installer per machine, and often has no outbound internet at all. Both cases are supported by the same archive.

Download the platform archive once from the licence portal, put it on your image or file share, and point machines at it. Activation can be done once for the site rather than per machine:

# On a build or image host, no internet needed after this step $ tar -xzf uqu-0.1.0-x86_64-linux.tar.gz -C /opt $ /opt/uqulang/bin/uqu licence activate --offline licence.jwt $ ln -s /opt/uqulang/bin/uqu /usr/local/bin/uqu # Verify on a lab machine $ uqu doctor

Site licences include an offline activation file so lab machines never contact a licence server. Ask your administrator, or open a support request.

Editor support

uqu lsp implements the Language Server Protocol, so any editor with an LSP client can get diagnostics, completion, go-to-definition and formatting. Editor plugins are distributed through the licence portal and the usual editor marketplaces.

Uninstall

Delete the toolchain directory and the shim on your PATH. There is nothing else — no system services, no registry keys, no files outside these two locations.

$ rm -rf ~/.uqulang $ rm ~/.local/bin/uqu
