Errors

enum ParseError { Empty, BadDigit(byte), } func parse_u32(text: str) throws ParseError -> u32 { guard text.len > 0 else { throw ParseError.Empty } var value: u32 = 0 for ch in text.bytes() { guard ch >= '0' and ch <= '9' else { throw ParseError.BadDigit(ch) } value = value * 10 + u32(ch - '0') } return value } // Errors are values, and the compiler will not let you drop one. match try parse_u32("40two") { case .ok(let n): io.println("{}", n) case .err(let why): io.eprintln("bad input: {}", why) }

module image // No bindings generator, no wrapper library, no marshalling layer. extern "C" { func stbi_load(path: *u8, w: *i32, h: *i32, ch: *i32, want: i32) -> *u8 func stbi_image_free(data: *void) } func load(path: str) -> ?Image { var w: i32 = 0 var h: i32 = 0 var channels: i32 = 0 let pixels = stbi_load(path.c_str(), &w, &h, &channels, 4) guard pixels != nil else { return nil } defer stbi_image_free(pixels) return Image.copy(pixels, usize(w), usize(h)) }
Why uqulang

A small language that stays out of the way

Systems work asks two things of a language: predictable machine behaviour, and code a team can still read in five years. uqulang is designed so you never trade one for the other.

Ahead-of-time, always

One native binary, statically linked by default. No interpreter, no JIT warm-up, no runtime to ship alongside your program.

Reads like Swift

Modules, traits, optionals, pattern matching and real generics — the vocabulary you already know, without the header files.

Memory you can account for

Scope-based ownership and defer. Every allocation has a visible owner, and nothing runs behind your back to free it.

C without a wrapper

Declare a C function, call it. Matching ABI, matching layout, zero overhead — and your uqulang library is callable from C in return.

One toolchain

Build, test, format and document with a single uqu binary. No project generator, no plugin ecosystem to keep alive.

Errors that can't be ignored

Typed throws, checked at the call site. No exceptions unwinding through code that never expected them.

uqulang is pre-1.0, and we say so on the front page.

The language and its compiler are under active development. Syntax can still change between preview releases, and every change is written down in the release notes. Read the roadmap before you build production infrastructure on it.

Deterministic by design

You can read the cost off the page

There is no hidden allocation, no implicit copy of a large value, and no collector deciding when your latency spike happens. What you write is what the back end emits.

  • Values are stack-allocated unless you ask for the heap.
  • defer runs at scope exit, in reverse order, always.
  • Moves are explicit; a copy of an owning type is a compile error.
  • No hidden control flow: no destructor magic, no operator surprises.
func read_all(path: str) throws io.Error -> Buffer { let file = try io.open(path, .read) defer file.close() // runs on every exit path let size = try file.size() var buf = Buffer.with_capacity(size) defer_on_error buf.free() // released only if we throw try file.read_into(&buf) return move buf // ownership moves to the caller }
Performance

Measured, then published — never the other way round

uqulang targets the same machine code quality as a C compiler at -O2, because it lowers to the same kind of IR and makes the same guarantees about aliasing and layout. We publish a number only when you can reproduce it.

In the classroom

Small enough to teach in one semester

uqulang is licensed to universities because that is who it was designed for: a language a student can hold in their head, on a toolchain that behaves the same on every machine in the lab.

One binary per lab machine

No package manager, no per-student environment setup, no “it works on my laptop”. Copy one file, or deploy the whole lab from an offline image on an air-gapped network.

Reproducible builds for grading

The same source and the same toolchain version produce a byte-identical binary. Submissions compile the same way on the marker’s machine as on the student’s.

The concepts a systems course needs

Pointers, layout, stack versus heap, ownership, the ABI — all visible in the source rather than hidden behind a runtime, so a lecture can point at the line where the cost is.

Diagnostics that teach

Every error names what the compiler expected, what it found, and the rule involved. Students spend the lab on the concept, not on decoding the message.
