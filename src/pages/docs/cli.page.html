The uqu command

One binary does the whole job: compile, run, test, format, document and serve the language server. Every subcommand accepts --help.

Covers toolchain 0.1.0

Synopsis

$ uqu [options] [paths]
CommandWhat it does
initCreate a project in a new or empty directory
buildCompile to a binary or library in target/
runBuild, then execute, forwarding arguments
testCompile and run every test block
fmtFormat source in place; one canonical style
docGenerate HTML API documentation from doc comments
checkType-check without producing a binary
fixApply mechanical migrations after an upgrade
lspSpeak the Language Server Protocol over stdio
doctorReport the toolchain, linker and target it can see

uqu build

$ uqu build --release $ uqu build --target x86_64-unknown-linux-gnu $ uqu build --emit asm --out build/
--release
Optimise (opt=speed), strip debug info, remove test blocks and debug assertions.
--opt <level>
debug, size, speed. Defaults to debug.
--target <triple>
Cross-compile. Run uqu targets for the supported list.
--emit <kind>
bin, lib, obj, asm, ir. Useful for inspecting what was generated.
--static / --dynamic
Link the standard library statically (default) or against a shared object.
--out <dir>
Output directory. Defaults to target/<profile>/.
-j <n>
Parallel compilation jobs. Defaults to the core count.

uqu run

Everything after -- goes to your program, not to the compiler.

$ uqu run -- --input data.csv --verbose

uqu test

$ uqu test $ uqu test --filter checksum $ uqu test --jobs 1 --fail-fast
--filter <text>
Run only tests whose name contains the text.
--fail-fast
Stop at the first failure.
--jobs <n>
Run tests in parallel; 1 makes ordering deterministic.
--format <kind>
pretty (default) or json for CI ingestion.

uqu fmt

One style, no options, so formatting never becomes a review topic. Use --check in CI to fail on unformatted code.

$ uqu fmt $ uqu fmt --check src/

Exit codes

CodeMeaning
0Success
1Compilation error, test failure, or unformatted code under --check
2Bad usage: unknown flag, missing argument
101Internal compiler error — please report it with the source that triggered it

Environment

UQU_HOME
Toolchain directory. Defaults to ~/.uqulang.
UQU_CACHE
Build cache location. Delete it freely; it only costs time.
UQU_TARGET
Default target triple, overridden by --target.
NO_COLOR
Any value disables coloured diagnostics.

Using it in CI

The toolchain is a single archive with no installer, which makes CI setup three lines. Pin the exact version so a new release never changes a build that used to pass.

- run: curl -fsSL https://get.uqulang.com/install.sh | sh -s -- --version 0.1.0 - run: uqu licence activate --offline "$UQU_LICENCE" # from a CI secret - run: uqu fmt --check - run: uqu test --format json
