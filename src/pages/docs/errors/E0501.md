## What it means {#meaning}

A struct literal must give a value for every field. There is no partial
initialisation and no zero value filled in behind your back.

## An example that triggers it {#example}

```uqulang
struct Rect {
    w: f32,
    h: f32,
}

let r = Rect{ w: 2.0 }      // error[E0501]: missing field `h`
```

## How to fix it {#fix}

Give the field a value:

```uqulang
let r = Rect{ w: 2.0, h: 3.0 }
```

If most uses share a value, write a constructor and call that instead:

```uqulang
impl Rect {
    pub func square(side: f32) -> Rect {
        return Rect{ w: side, h: side }
    }
}
```

## Why the rule exists {#why}

Adding a field to a struct should force you to visit the places that build it.
If the compiler filled in a default, those places would keep compiling and
quietly mean something different.
