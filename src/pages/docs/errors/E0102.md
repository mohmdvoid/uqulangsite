## What it means {#meaning}

`let` binds a value once. `var` binds one that can be reassigned. The
distinction is not a style preference: the compiler relies on it when deciding
what it can keep in a register and what it must reload.

## An example that triggers it {#example}

```uqulang
let limit = 4096
limit = 8192        // error[E0102]: cannot assign to an immutable binding
```

## How to fix it {#fix}

If the value genuinely changes, bind it with `var`:

```uqulang
var limit = 4096
limit = 8192
```

If it does not, you probably meant a second binding:

```uqulang
let limit = 4096
let doubled = limit * 2
```

## Why the rule exists {#why}

Most bindings never change. Making that the default means the ones that do
change stand out in the source, which is where a reader looks for the cause of
a bug.
