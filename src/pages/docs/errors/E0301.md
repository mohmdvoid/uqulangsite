## What it means {#meaning}

`match` must handle every case its subject can take. The message lists the ones
that are missing.

## An example that triggers it {#example}

```uqulang
enum Shape {
    Circle(radius: f32),
    Rect(w: f32, h: f32),
    Point,
}

func area(s: Shape) -> f32 {
    match s {                       // error[E0301]: `.Point` is not covered
        case .Circle(let r): return 3.14159 * r * r
        case .Rect(let w, let h): return w * h
    }
}
```

## How to fix it {#fix}

Cover the missing case:

```uqulang
        case .Point: return 0.0
```

Or use `default` when the remaining cases genuinely share behaviour. Prefer
listing them while the enum is small — that is what makes adding a variant safe
later.

## Why the rule exists {#why}

The value of exhaustiveness is not in the match you are writing now; it is in
the one you forget to update in eighteen months. Adding a variant to an enum
turns every incomplete match into a compile error instead of a wrong answer at
run time.
