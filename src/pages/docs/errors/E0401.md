## What it means {#meaning}

The function is marked `throws`, so the call can fail, and the failure is not
being dealt with at the call site.

## An example that triggers it {#example}

```uqulang
func main() {
    let text = fs.read_to_string("names.txt")   // error[E0401]: unhandled error
    io.println(text)
}
```

## How to fix it {#fix}

Propagate with `try`, which requires the caller to be `throws` as well:

```uqulang
func main() throws {
    let text = try fs.read_to_string("names.txt")
    io.println(text)
}
```

Handle it here with `match`:

```uqulang
    match fs.read_to_string("names.txt") {
        case .ok(let text): io.println(text)
        case .err(let why): io.eprintln("cannot read names.txt: {}", why)
    }
```

Or state that you are ignoring it, which is deliberately ugly and easy to grep
for:

```uqulang
    discard try fs.read_to_string("names.txt")
```

## Why the rule exists {#why}

An ignored error is a decision. Making it visible in the source means a reviewer
can see it, and a search can find every one of them before a release.
