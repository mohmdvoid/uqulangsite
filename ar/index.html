لغة uqulang لغة برمجة مترجَمة للأنظمة، لمن يحتاج أن يعرف بالضبط ما ستفعله الآلة، ويريد في الوقت نفسه شيفرة تُقرأ بسهولة. تُترجَم مسبقاً إلى ملفات تنفيذية أصلية: بلا بيئة تشغيل، وبلا جامع مهملات.

module hello

import std.io

func main() {
    let names = ["عالم", "world", "мир"]

    for name in names {
        io.println("مرحباً، {}!", name)
    }
}
لماذا uqulang

لغة صغيرة لا تقف في طريقك

برمجة الأنظمة تطلب أمرين: سلوكاً يمكن التنبؤ به على مستوى الآلة، وشيفرة يستطيع الفريق قراءتها بعد خمس سنوات. صُمِّمت uqulang كي لا تضحّي بأحدهما مقابل الآخر.

ترجمة مسبقة دائماً

ملف تنفيذي أصلي واحد، مرتبط استاتيكياً افتراضياً. بلا مفسّر، وبلا بيئة تشغيل تُشحن مع برنامجك.

تُقرأ مثل Swift

وحدات، وسمات (traits)، وأنواع اختيارية، ومطابقة أنماط، وأنواع عامة حقيقية — بلا ملفات ترويسة.

ذاكرة يمكنك حسابها

ملكية مرتبطة بالنطاق مع defer. لكل تخصيص مالك ظاهر، ولا شيء يعمل خلف ظهرك ليحرّره.

تكامل مع C بلا غلاف

صرِّح بدالة C ثم استدعِها. نفس الـ ABI ونفس التخطيط وبلا كلفة إضافية، والعكس صحيح أيضاً.

أدوات في ملف واحد

البناء والاختبار والتنسيق والتوثيق عبر الأمر uqu وحده. بلا مولّد مشاريع وبلا إضافات.

أخطاء لا يمكن تجاهلها

‏throws بنوع محدّد، يُفحص عند موضع الاستدعاء. بلا استثناءات تمرّ عبر شيفرة لم تتوقعها.

‏uqulang ما تزال قبل الإصدار 1.0، ونقولها في الصفحة الأولى.

اللغة ومترجمها قيد التطوير النشط، وقد تتغيّر الصياغة بين الإصدارات الأولية. راجع خطة الطريق قبل اعتمادها في مقرّر دراسي قائم.
